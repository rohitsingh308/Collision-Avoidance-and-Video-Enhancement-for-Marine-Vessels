# 🚢 Collision-Avoidance-and-Video-Enhancement-for-Marine-Vessels



This project is an AI-powered real-time **collision avoidance system** designed for marine environments. It captures **live video feed** from a ship, detects nearby vessels using **object detection**, and provides **directional commands** (e.g., "Turn Right", "Turn Left") to avoid collisions. Simultaneously, the system performs **video enhancement** to improve visibility in **low-lighting conditions**, ensuring safer navigation.



---

## ✨ Features

- 🎥 **Live Feed Analysis** from onboard cameras.
- 🧠 **Object Detection** using YOLO for vessel identification.
- 💡 **Low-Light Video Enhancement** using MIRNetv2 or custom deep learning model.
- ⚠️ **Collision Prediction** and avoidance instruction display.
- 🌊 **Underwater Use-case Support** through visibility enhancement.
